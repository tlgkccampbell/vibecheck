The solution is too large to list type by type, so the listing below groups its types by namespace. Each `=== Namespace ===` header gives the number of types the namespace declares in brackets, and a line starting with `in` names the assemblies that declare them when there are several. The next line names the namespace's largest units by their head types, where a unit is a type together with the helpers that only it uses. The quoted lines are the documentation summaries of a few of those types. The lines starting with `->` and `<-` name the namespaces it references most and is referenced by most, with counts of references.

Bind by namespace pattern: `Example.Billing.*` binds the types of one namespace, and `Example.Billing.**` binds those of the namespaces beneath it as well. A leaf may bind several namespaces. At this size a leaf may hold a whole namespace however many types it has, so split a namespace only where its sub-namespaces divide it. Use an exact type name only for a type the listing names that plainly belongs with another namespace, and use few of them, since every exact name makes the map longer.
