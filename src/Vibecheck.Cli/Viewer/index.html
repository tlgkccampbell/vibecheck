Reading the diagram
  • Hexagons are things outside this level. Grey hexagons are external assemblies.
  • Each edge is one curve from user to used, bowing to its left. Its width grows with the log of its references.
  • Changed edges carry labels and arrows. A change under 3 references or 1% is minor and unlabeled.
  • Reviewed means every changed file beneath is set aside. A file whose edits touch only comments, whitespace or layout, and a file renamed without changes, start reviewed. Turn off Mute reviewed files to show them as they are.
  • Other files holds the changed files that no type binds, such as project files, documents and workflows.
  • Hover a block to trace its edges.
